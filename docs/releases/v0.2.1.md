The first ready-built release of Maprisma Control, the bar icon that starts and stops Maprisma: a panel applet on COSMIC and a tray icon on KDE Plasma and Hyprland (in a bar with a system tray, e.g. Waybar or Quickshell). No Rust needed: unpack `maprisma-control-0.2.1-x86_64.tar.gz` and run `./install.sh`.

- Installs both integrations, each only active on its desktop. COSMIC: add "Maprisma Control" in COSMIC Settings › Desktop › Panel › Applets. KDE and Hyprland: the tray starts now and at every login; on Hyprland without uwsm the installer prints the line for your hyprland.lua.
- Finds Maprisma wherever it is: `~/.local/bin`, your PATH, an /opt install or an AppImage (after its first start).
- Checks the libraries first and names the packages for your distribution; never replaces files that are not its own, nor a Control managed by Maprisma Settings; an interrupted install is rolled back by the next run. `~/.local/lib/maprisma-control/uninstall.sh` removes it again.
- Built on Ubuntu 24.04: runs on glibc 2.39 or newer (Arch, Fedora 40+, Ubuntu 24.04+, Pop!_OS 24.04, Debian 13). Tested on fresh Arch installs of COSMIC, KDE Plasma and Hyprland, and on Ubuntu 24.04.

**File:** `maprisma-control-0.2.1-x86_64.tar.gz` with its `.sha256`.
